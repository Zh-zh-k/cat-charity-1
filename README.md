# QRKot

QRKot — API-сервис благотворительного фонда поддержки котиков.

Фонд собирает пожертвования на различные цели: корм, лечение, содержание
приютов и другие проекты, связанные с помощью кошкам и котятам.

Пользователи могут отправлять пожертвования в фонд, а средства автоматически
распределяются между открытыми благотворительными проектами.

## Возможности

В приложении можно:

- создавать благотворительные проекты;
- получать список всех проектов;
- редактировать открытые проекты;
- удалять проекты, в которые ещё не были инвестированы средства;
- создавать пожертвования;
- получать список пожертвований;
- автоматически распределять пожертвованные средства между проектами.

## Распределение пожертвований

Пожертвования поступают в фонд, а не в конкретный проект.

Средства автоматически направляются в самый старый из открытых проектов.
Если пожертвование полностью закрывает потребность проекта, оставшаяся сумма
переходит к следующему открытому проекту.

Если открытых проектов нет, нераспределённая часть пожертвования сохраняется.
При создании нового проекта свободные пожертвования автоматически
инвестируются в него.

Когда проект получает всю необходимую сумму, он автоматически закрывается.

## Установка и запуск

Клонируйте репозиторий и перейдите в директорию проекта:

```bash
git clone git@github.com:Zh-zh-k/cat-charity-1.git
cd cat-charity-1
```

Создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте его.

Для Linux/macOS:

```bash
source venv/bin/activate
```

Для Windows:

```bash
venv\Scripts\activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Примените миграции:

```bash
alembic upgrade head
```

Запустите приложение:

```bash
uvicorn app.main:app --reload
```

После запуска API будет доступен по адресу:

```text
http://127.0.0.1:8000
```

## Эндпоинты

### Благотворительные проекты

- `GET /charity_project/` — получить список проектов;
- `POST /charity_project/` — создать новый проект;
- `PATCH /charity_project/{project_id}` — изменить открытый проект;
- `DELETE /charity_project/{project_id}` — удалить проект, если в него ещё не
  были инвестированы средства.

### Пожертвования

- `GET /donation/` — получить список пожертвований;
- `POST /donation/` — создать пожертвование.

Пожертвования нельзя изменять или удалять через API.
